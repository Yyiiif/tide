# Demo dataset

Prototype-aligned sample expenses for UI previews. Served at `/data/demo/*`. Loaded only when demo mode is on (see repo root `README.md`).

- `config.json` — month, today, budget, per-category budgets
- `expenses.json` — expense rows (Jul–Dec 2026 sample)

Edit these files to change demo content; no need to touch `index.html`.
